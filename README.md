# Academic Management System (OOP C++)

A C++ console application that models an academic registry system using Object-Oriented Programming (OOP) principles including inheritance, polymorphism, and dynamic memory management.

## Key Concepts Demonstrated

- **Inheritance:** `Student` and `Teacher` classes derive from a base `Person` class.
- **Polymorphism:** Method overriding (`displayInfo`) via virtual functions.
- **Dynamic Memory Management:** Pointer manipulation and clean execution using `vector<Person*>`.

## Tech Stack

- **Language:** C++ (C++11 or higher)
- **Paradigm:** Object-Oriented Programming (OOP)
